## About Me

我喜欢把想法做成能被真实使用的东西。这个主页会持续记录我的工程实践、工具探索、Web 应用和 AI 应用方向的成长轨迹。

我希望自己的代码库不只是“能跑”，还要能让后来的人看懂、接住、继续迭代。比起堆概念，我更在意问题是否被讲清楚、边界是否被处理好、交付是否真的有用。

```text
Think clearly -> Build simply -> Verify honestly -> Improve continuously
```

## How I Build

| Principle | Practice |
| --- | --- |
| Clarity first | 先定义问题、用户、边界，再写代码 |
| Small loops | 用可验证的小步推进，避免一次性赌太大 |
| Useful abstractions | 只在复杂度真实出现时抽象 |
| Reliable delivery | 注重错误处理、测试、文档和部署体验 |
